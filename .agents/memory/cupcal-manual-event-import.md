---
name: Manueller CupCal-Terminimport
description: CupCal-Termine kommen über den geschützten manuellen Dateiimport.
---

CupCal verwendet den freigegebenen manuellen Import gespeicherter MHT/MHTML-Spielpläne als Terminquelle. FortniteAPI.io soll nicht wieder als automatischer Import oder Sync ergänzt werden.

**Why:** Der Nutzer hat bestätigt, dass bereits ein manueller Terminimport besteht, und die Entfernung der zusätzlichen API ausdrücklich verlangt.

**How to apply:** Neue Terminimporte an den bestehenden Admin-Dateiimport anschließen. Keine automatische FortniteAPI.io-Verbindung ergänzen.
